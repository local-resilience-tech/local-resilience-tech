A project to have a static personal site hosted on a **Node**. This builds on the idea of Web 1.0 digital gardens / personal sites. This is a stepping stone project for a deeper understanding of the web and sites should be accessible both over the internet and across the **Region** through p2panda or alternative networks.

Simple static sites take very little resources to host and multiple sites could be integrated into a **Node** or **Node cluster**, each **Node Steward** could have their own static page!

## What success looks like

- A basic starter website that is easy to build off of, or can be overwritten.
- A comprehensive guide for basic web routing
- A followable setup process for p2panda and offline routing methods
- Web hosting has continuous integration from a git repository on the node
- Website is accessible at a local URL if on the same network as a node
- Website is accessible at a public subdomain specific for each node

## Non-goals

The following things are specifically out of scope for this project, even though they might be good ideas in the future:

- Responsive design
- Javascript
- Building features like blog posts etc.
- Distributing an archive of the website
