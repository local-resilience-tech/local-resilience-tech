To see the website archives available at other nodes in the region, we're going to need to bind our Kiwix app to a particular region
{{</hero>}}

## Registering

This is pretty straight forward. In LoRes Node, while logged in as a **Node Steward**, go to the list of local apps. You should see `lores-kiwix` there.

Simple press the button that says **"Register with REGION_NAME"**

{{< figure src="local_app.png" alt="A screenshot from LoRes Node showing a local app, called lores-kiwix. It shows some details of the app, including that it's instance ID is instance-001. There is a main button at the bottom that says 'Register with naarm-solarpunk-test'" caption="The local app details page in LoRes Node">}}

_Note: If your node is part of more than one region, you'll need to select the region you want in the sidebar first._

- [x] Kiwix is displaying books from other nodes in your region
