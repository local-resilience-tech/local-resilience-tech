## What is maintenance?

Servers generally don't maintain themselves. For example, there are a lot of routine upgrades to do, and while we might hope to automate many of them, some will require manual intervention in order to manage risk, manually test the results, or inform users of downtime.

Server maintenance then, is the regular work we do to ensure that our server (in this case a **LoRes Node**) will run smoothly. If we do this well, then it should reduce the risk of an **Incident** (some sort of emergency that impacts our service or our users).

## Types of maintenance

Broadly, LoRes Node maintenance includes:

- [Software updates](software_updates)
- Data backups
- Resource usage tracking
- Hardware maintenance

Not all of these have guides on this site yet. Perhaps you'd like to help us write them.
